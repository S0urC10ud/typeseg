Paste text or select an example. **Mamba is selected for its full-file context**; choose U-Net in the visible Model selector for faster inference. Hover or select a region in the composition bar to see its location, then inspect the highlighted text.

Inference runs locally. The page downloads model assets; your input stays in the browser. The visible **Model** selector offers **U-Net**, **Mamba**, **U-Net-Sec**, and **Mamba-Sec**. General remains the default; Security specializes in mixed scripts and encoded payloads and can be less accurate on ordinary languages. [Evaluation details](../../security/performance/) cover the paper’s general and security-adapted models. Browser speed depends on your device and runtime.

The default mixed-content example matches `typeseg --demo`: CSS, JavaScript, HTML, SQL, and a shell command embedded in an HTML comment.
